# UniSphere - University Communication System (UCS)

UniSphere (UCS) is a modern University Communication System web interface prototype built using HTML, CSS, and JavaScript. Designed to connect students, lecturers, HODs, and administrators through a blue-themed responsive dashboard, announcements, and messaging features.

💡 **Project Background & Contribution**

While I spearheaded the core concept and front-end development of the UniSphere interface, this project was collaboratively executed as an academic assignment for the Department of Computer Science.

🚀 **Key Features**

* **Role-Based Login Interface:** Secure entry supporting multiple system roles (Students, Lecturers, HOD, Administrator) with JavaScript-powered credential validation.
* **Student Dashboard:** Displays student profile details, academic tracking meters, navigation menus, and real-time class schedules.
* **System Modules Layout:** Integrated sections for Announcements, Messaging, SMS Alerts, and Notifications.
* **Responsive UI Design:** Clean, professional blue-themed interface styled using modern CSS layouts.

🛠️ **Technologies Used**

* **HTML5:** Structuring the core elements of the login page and dashboard layout.
* **CSS3:** Custom styling, color schemes, container alignments, and visual enhancements.
* **JavaScript:** Handling user authentication flows and page-to-page navigation logic.
